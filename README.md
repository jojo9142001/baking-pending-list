# Baking Pending List

個人專屬輕量化烘焙主題待辦與業務追蹤工具。融合溫暖馬卡龍視覺美學、互動式趣味彩蛋與跨裝置即時狀態同步。

---

## 視覺與特色彩蛋

- 溫暖馬卡龍烘焙風格：全站採用粉橘蜜桃溫暖色系，搭配原創手繪向量招牌與烘焙專題看板。
- 杯子蛋糕月份業務區（Cupcakes of the Month）：將每月例行事務化為杯子蛋糕主題清單，支援月份標題點擊即改。
- 點擊爆米花互動動畫：背景隨機飄落金黃玉米粒，用滑鼠點擊即可瞬間爆開成香脆爆米花，工作之餘兼具解壓樂趣。
- 烘焙私房筆記（Recipe）：摺疊式收納區，便於隨時展開查看與複製常用交接信件範本與備忘錄。

---

## 核心功能

- 緊急程度視覺標記：內建 4 款手繪風格貼紙，可依任務的「緊急程度與優先順序」自由拖曳標記，直覺一眼辨識。
- 互動式任務看板：支援臨時事項新增、打勾完成劃線、貼紙重設與長按拖曳調整順序。
- 跨裝置雲端同步：自動連線同步狀態，手機與電腦隨開隨用、雙向即時更新。
- 本機快照與備份站：本機離線優先儲存，並支援一鍵產生與還原 Base64 食譜備份碼。
- 零依賴單檔架構：純前端原生開發，免編譯環境，雙擊或透過 GitHub Pages 即開即用。

---

## 操作指南

1. 於瀏覽器開啟 GitHub Pages 專屬網址。
2. 頂部輸入框鍵入文字並按 Enter 即可新增任務。
3. 依照事項的「緊急程度」，由上方貼紙列拖曳對應圖案至任務方框中標記。
4. 點擊任務上的貼紙方框可清除圖案；點擊任務右側碎紙桶可刪除事項。
5. 點擊背景飄落中的玉米粒，可觸發爆米花彈跳動畫。
6. 於「食譜備份與雲端同步站」輸入專屬同步碼，即可在多裝置間同步最新進度。
